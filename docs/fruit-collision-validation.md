# 水果连续碰撞验证

- 问题：下落水果相互接触时出现可见穿入。现有刚体默认 bullet=false，动态物体之间依赖离散检测。
- 修改：FruitSpawner.spawnOne 在节点挂入活动场景前设置 fruit.body.bullet=true，同时先设置出生坐标。Creator 3.8.8 在创建底层刚体时读取 bullet，创建后再赋值无法保证生效。普通生成与黑洞补果共用该路径。
- 保留：原版多边形、重力、步长、摩擦、页面布局和用户编辑的 main.scene。

## 边界

连续检测针对运动过程的穿透，不会自动修复关卡初始坐标重叠、关闭碰撞期间的重叠或素材轮廓误差。本次没有把截图原因宣称为唯一确定；若同位置仍稳定重叠，需要结合具体关卡和操作复现继续检查。
