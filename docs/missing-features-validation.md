# 缺失功能补齐记录

## 已接入

- 原版首页背景、标题、开始按钮、当前关卡、主题和设置入口；编辑器入口保留。
- 水果/甜品主题图鉴，各30个格子。通关逐个点亮甜品；第30关通关后才可使用甜品主题。选择单独持久化，试玩不改变正式关卡进度。
- 30套甜品预制体使用原版独立多边形和尺寸，仍按1至30逻辑编号配对。普通生成和黑洞补果共用主题选择。
- 背景、地形、锁墙、袋口、袋身跟随主题。锁墙和袋子通过各自预制体内的ThemeSprite绑定，避免跨嵌套组件引用在保存后丢失。
- 编辑器跟随主题显示图标；新增水果根据实际图片半径加原版8像素间隔寻找空位。采用确定性扫描，不回退到重叠位置。
- 旧b=true或b=t黑洞宿主标记规范化；自动分配不冲突编号并保留严格的非法字段检查。
- 成功音效使用原succes.mp3，并服从声音设置；结算关闭停止播放。
- 入袋缩小的0.1秒同步渐隐，和水果位移共用补间生命周期。
- 浏览器震动能力检测、20毫秒短震、100毫秒节流和设置门禁；不支持的平台保留设置但明确提示。原生/小游戏可注入适配器，尚未接渠道SDK。

- 原版水果/甜品隐藏提示专用文字图片均已绑定，随主题切换。
