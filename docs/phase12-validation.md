# 激励广告门禁与扩槽

对照原 GameSc.lockWallOnclick，完整广告结果后移除锁墙；getLoseFloorBallThreshold 从4变5。本阶段同步物理、图片、按钮和判负规则。原危险提示阈值从3变4已确认，但危险闪烁与音效尚未迁移，不能称其反馈完成。

RewardGate 提供 expand-slot、revive、prop 用途接口，当前仅扩槽实际接入。适配器返回请求编号、用途、完成状态与来源；门禁校验并发、来源、请求一致性和页面代次，页面再次检查本局是否仍可发奖。过期、取消、失败不发奖。平台完成结果仍需要未来真实SDK可靠回调，不包含服务端验证。

DevelopmentRewardPanel 是 Creator MCP 制作的独立开发模拟预制体，提供完整观看、提前退出、播放失败三种手动结果，标注不产生广告收入。仅DEV环境加载并接受开发来源；正式构建没有适配器时返回不可用，不静默模拟成功。真实SDK与发布构建回归仍在最后阶段。

LockWallView 为独立预制体，原图163×95设计像素，碰撞盒80×90，挂载位置(0,-466.325)。解锁先停用刚体再隐藏图片，不同时停用碰撞体和节点。每局新实例恢复锁定；成功后按钮不再接受请求。输入提示与入场期间不允许发起扩槽。

实际第2关验证：模拟提前退出后锁墙保留并显示取消说明；模拟失败后锁墙保留且可重试；模拟完成后图片和阻挡移除。点击底部两颗水果后实际进入更深槽底，未出现物理或加载错误。设置重开后恢复40水果与锁墙，返回主页正常，最终日志无警告或错误。

测试：test-reward-gate 覆盖完整结果、生产环境拒绝开发来源、错误编号/用途/来源、取消失败、并发和跨局请求；test-slot-expansion 使用真实棋盘、锁墙和失败规则，覆盖一次性扩槽、物理/图片同步、4个与5个的静止及接触判负边界、新实例重锁。开局顺序测试通过，47个预制体引用有效；assets业务代码无TypeScript诊断。

未验证/未完成：真实广告播放与收入、后台恢复、广告期间恰好结算的实机流程、5个不同水果实际失败样例、危险提示表现、复活与道具奖励。开发模拟不暂停底层物理，若期间结束本局，结果不再发放；真实平台生命周期需在SDK接入时专项验证。
