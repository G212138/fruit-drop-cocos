# 首页游戏资源预加载

首页onShow通过XForge UIManager.load提前安装并缓存PageGame预制体及依赖；并行加载page-game-res中的关卡数据、星星、草叶、首关引导和设置。开发环境额外加载模拟奖励面板。

预加载不调用show、不实例化UI节点、不启动关卡、不推进存档；玩家点击开始仍通过框架进入游戏。缓存和重复请求交由现有加载器管理。

已验证正式/开发资源范围、首页不启动游戏和开始入口；TypeScript无assets诊断。未实测耗时，不宣称彻底消除卡顿：首次网络读取、实例化和Spine初始化仍可能有开销；用户打开首页后立即点击时预加载也可能尚未完成。
