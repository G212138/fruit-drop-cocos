# 场地容器摇晃

点击“晃一晃”后，地形、锁墙、左右边界和未点击水果构成同一个移动容器。固定刚体临时切换为 Kinematic，通过线速度左右往返；自由水果保持 Dynamic、原有重力和速度，仅通过真实碰撞受到容器影响。不再使用单体视觉偏移、弹簧回弹或随机推力。

- 手感适配参数集中在 FruitShake.SHAKE_RULES：持续 1 秒、往返 2 周、位移包络上限 18 世界像素，首尾位移和速度归零；开始间隔 3 秒。
- 背景、袋子与消除特效层跟随实际容器位移；设置、关卡、进度和道具 HUD 不动。背景在运动期间横向扩宽 8%，结束恢复缩放。
- 固定水果含冰冻水果，相对容器保持位置不变；悬停水果的业务接触不触发落地或配对。自由水果照常碰撞、滚动、反弹和消除。
- 运动中点击水果时，先解除容器绑定，在当前位置按正常流程下落；结束不把它拉回原位置。
- 正常结束和中断只恢复固定部分的位置与刚体类型，不清空自由水果速度。补位、道具、扩槽在摇晃期间禁用，避免同时改动场地。
- 复用 PageGame 的既有按钮和八种语言，无运行时创建 UI，无序列化资产变更。
- 手机输入仍经 ShakeGesture 与 PhoneShakeInput：两次至少 1.2 g 的变化，间隔 60—500 毫秒；退出和后台解除监听。TikTok 缺少对应接口时保留按钮，不承诺手机传感器可用。

验证：test-fruit-shake.cjs 检查运动学容器速度一致、动态水果原速度保留、固定部分归位、中途点击释放、冷却及手机监听生命周期。测试中的积分不替代引擎碰撞验证。另运行水果生命周期测试和业务 TypeScript 检查。Native 构建与真机验证由用户操作。

浏览器验证：在 localhost:7456 第 2 关释放一个水果后点击摇晃，检查场地归位与自由水果保留，控制台未捕获 error。短时截图不能代替连续运动和真机手感验收。

边界：摇晃用于容器运动反馈，不保证解除所有夹缝卡住情况。力度与真机手感可在上述参数中继续调整。
