# 水果解卡

- PageGame 的 TopBar 内嵌“晃一晃”按钮，复用已有空白按钮图，不新建独立预制体。按钮接入现有八种语言。
- 免费使用；成功推动后冷却 3 秒，暂停不推进冷却，没有符合条件的水果不占冷却。
- 只推动已经释放、速度不超过 0.6 物理米/秒的动态水果，排除悬停、冰冻、消除及黑洞出现中的单体。
- 水平速度增量为 1 米/秒，向上增量为 1.2 米/秒，冲量乘以刚体质量，左右交替；不改坐标、不关闭碰撞、不直接消除。
- 设置面板、结算、广告暂停、入场、补位、道具与复活动画期间禁止解卡。传感器回调只排队，物理冲量在帧更新中执行。
- 手机摇晃通过 Cocos 加速度输入识别，两次至少 1.2 g 的变化、间隔 60 至 500 毫秒才触发；退出页面和进入后台解除监听。
- 当前 TikTok 官方 SDK 文档未确认加速度接口支持；运行时缺少对应接口则不启动传感器。不能承诺 TikTok 支持摇一摇，按钮入口始终保留。原生 Android/iOS 和 TikTok 实际能力及解卡力度仍由用户真机验证。未执行真机构建。

验证：解卡规则与传感器生命周期回归测试、语言测试、PageGame 预制体引用检查、启动依赖检查通过；业务 TypeScript 无错误。浏览器第 2 关确认按钮显示、有效点击水果下落和点击解卡无新增 error。未对所有夹缝形状完成物理效果验收。

模块：FruitShake 负责冲量与冷却，ShakeGesture 负责纯手势识别，PhoneShakeInput 负责输入生命周期；GameBoard 和 PageGame 负责组合与状态门禁。
