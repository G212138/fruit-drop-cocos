# 首页音画与首进调整（2026-09-14）

首页及游戏内现有按钮统一通过 UiClickSound 播放 audio/drop（复用下落声，音量 0.65），隐藏弹窗同样覆盖，重复进入不重复绑定。遵循音效设置。首页调用既有 SettingsController 播放音乐，离开时停止，音乐和音效设置独立。

首页和加载页背景已替换为去云版本。首页 CloudLayer 内有三朵独立透明云，Widget 控制行布局，HomeCloudMotion 只改变装饰图片横坐标；速度为 10、-7、8 设计像素/秒，离屏后循环。首页其他节点布局不变。编辑器工具为 tools/cloud-authoring.ts。

FirstLaunch 位于启动包，避免引用未加载业务包。新存档直接 PageGame；已进入标记或有效关卡存档则 PageHome。AppInit 按所选页面加载依赖，在首屏显示完成后记录标记。读写失败不阻断体验，不修改关卡与道具数据。

美术使用内置 image_gen，提示词：移除原首页背景全部白云，以同色天空渐变补齐，保留草地、叶片、苹果和甜甜圈的位置及尺寸；独立透明云为柔软白色、淡青底部阴影、卡通手绘质感、完整轮廓无文字。产物为首页 resources/redesign/background.png、cloud.png 和 app-appinit/res/background.png。

验证：启动单测覆盖新旧本地存档与 TikTok 存储、加载失败重试和标记写入时机；预制体引用有效。独立浏览器首进标记写入成功，首次直接关卡；无运行错误。不执行 Native 真机构建。

关卡编辑器入口启用状态交由预制体控制，不再按 DEV 动态显示。游戏新增的预制体弹窗自动绑定点击声，重复绑定通过弱引用去重，水果触摸事件不叠加按钮声。
