# 入场动画与中途退出验证

新增 EntryRules 和 EntryFlow，分别负责纯参数计算和水果实例的入场移动。纵向从上方进入，横向从左侧进入；动画期间锁定点击、自动释放与失败计时。没有运行时创建 UI 节点。

原版入场参数：场外边距 80 设计像素，距离除以 900 像素/秒得到时长，再限制在 0.25 至 1.2 秒；采用 sinOut 缓动。当前边界使用棋盘 UITransform 尺寸，其他屏幕比例仍需验证。为适配 3.8.8，入场时停用整个刚体，结束恢复原开关状态。

中途退出曾复现 Box2D b2GrowableStack.Pop 异常。仅在 onHide 清理或跳过冻结停用刚体不足以解决。现返回前先释放棋盘，水果销毁前先停用刚体，再切换页面，避免把活跃物理实例留到页面隐藏后清理。未修改引擎或 XForge 核心。

实际验证：第2关 40 个水果入场完成后点击水果并中途返回主页，再进入第2关重复操作。修改前有异常，修改后连续两轮返回及重新进入无新增错误，最后错误时间仍是修复前的 2026-09-07 18:43:09 UTC。此记录不代表全部关卡通关。

自动测试：test-entry-flow.cjs 覆盖方向、边距、时长上限下限、动画推进、完成与中断恢复、空列表；水果生命周期与黑洞流程测试通过。

未完成：入场前原版引导弹窗、横向入场实际体验、黑洞和冰层混合入场、各屏幕比例及入场中退出的实机回归。暂停、主题、道具、复活和完整反馈仍按总进度表推进。
