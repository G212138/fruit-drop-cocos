# 图鉴收藏册与弹窗渲染优化

图鉴沿用主题弹窗共享的 dialog-panel、dialog-header、dialog-close 图片。内部为3列×4行，两组各30件原始物品；横向滑动只浏览，纵向滚动独立记忆。方向锁定阈值12设计像素，换页阈值为视口宽度16%，取消和不足阈值回弹，过渡0.24秒。

页头采用两行：左侧品类图标和名称，右侧收集数；下方细进度条，分页点位于列表底部，两侧提供金色箭头切页按钮，首尾不可用按钮置灰。物品100×100，名称156×48、24号字，统一上移6设计像素，可容纳两行，八种语言各60个名称。全部解锁的组可点击“使用这组”；当前组显示“使用中”；选择保存后供 GameTheme.refresh 读取。水果保持原有默认全部开放，甜点保持每通关一关解锁一个，通关30关后整组可使用。浏览与关闭不保存选择，写入失败回退并使用框架Toast。

## 资源

使用内置 imagegen 按用户确认的蓝边奶油收藏册效果图制作无文字UI切图，并按实际尺寸裁剪、缩放保留透明度。独立图片位于 assets/app-bundle/app-view/pop/collection/resources/textures/album-*.png。仅包含普通/锁定卡片、进度底槽和填充、分页点、小锁、滚动条；外层三个元素直接复用主题共享资源。没有新增物品图集、地块图集、物品或地块缩略图；继续引用原始 shared-items 和 shared-terrains 图片，打包合图遵循项目配置。

制作提示词：以确认的图鉴效果图为风格参考，生成透明背景、正视、互不重叠的立体游戏UI素材，奶油卡片、冷灰锁定卡片、内凹进度槽、金黄填充条、蓝色滚动条、金色小锁和蓝色/米色分页点，无文字无水果；保持圆角、高光、柔和阴影，边缘干净。第二次编辑仅移除所有元素外背景及大范围光晕，保留不透明内部与抗锯齿轮廓。最终切图按原尺寸导入，未采用的外框与临时图集已移除。

## 渲染

CollectionVisibility 在滚动后只启用可见区域的Sprite/Label，整页不可见时只停用渲染组件，保留触摸节点以免跨页拖动中断。卡片底图、物品、名称和锁按层排列，名称使用字符缓存以便合批；保留一个外层裁切遮罩。TerrainVisibility 同步停止不可见地块的原圆角Mask及按钮，主题也将同类绘制层集中；不改原图，不复制缩略图。所有结构由Creator编辑器API保存。
