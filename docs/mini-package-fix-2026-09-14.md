# 真机分包与体积修复

同优先级资源包重复包含 Bold 和英文字体，构建器把正式页面的字体依赖重定向到 page-editor-res。首页资源包优先级改为5（其他资源包为4），明确共享字体归属。

新增项目扩展 mini-package-optimizer，已在当前 Creator 启用：构建结束后统一字体重定向，只删除与所属包字节完全相同的重复字体；将匹配源摘要的启动背景换为同分辨率 JPEG。以后更换启动背景时不会错误替换新图片。保持当前 MD5 Cache 关闭，其他配置暂不支持。

当前 build/bytedance-mini-game 已执行优化：总包 28,859,587 字节（27.52 MiB），主包 4,098,698 字节（3.91 MiB）；减少重复字体 3,946,688 字节。启动背景由1,130,314字节PNG转为107,525字节JPEG，尺寸852x1846不变。

node tools/test-mini-package.cjs 验证所有资源重定向目标、正式页面不依赖编辑器包、重复执行幂等和30MiB/4MiB门槛。本次没有操作真机，需在开发者工具重新编译当前输出后验证设备启动及平台实际包体检查。构建扩展已启用，但本轮未执行完整重建。
