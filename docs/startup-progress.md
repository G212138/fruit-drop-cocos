# 启动加载进度

AppInit 保留当前蓝天背景与 Tumble Match 标志，使用启动目录内的 `loading-bar.png` 展示绿色高光进度。该图片复制自首页按钮原图，不依赖首页资源包。进度条、填充和百分比均由 Creator 预制体绑定；Widget 控制位置，业务代码只更新进度与数字。

进度是实际完成阶段的加权值，不是下载字节百分比：框架初始化占 0～25%，启动依赖包注册占 25～65%，PageHome 预制体及依赖加载占 65～95%。框架通知首页展示成功后才报告 100% 并释放启动页。移除了原有固定两秒 Logo 淡出等待。

加载失败保持当前进度，一秒后重试；资源总数增加不会使百分比倒退。百分比无需翻译，不在首包导入业务多语言或首页动画脚本。

编辑入口：`assets/app-appinit/view/AppInit.prefab` 中的 `LoadingProgress`。设计尺寸为 540×64，中心纵向偏移 -270（Cocos 设计坐标单位）；可在编辑器调整 Widget 与尺寸。Fill 使用左侧锚点和 FILLED 模式，总填充长度为 1。

验证：`node tools/test-app-init.cjs` 覆盖延迟回调、分包和首页资源重试、进度不倒退、首页展示前不结束。Creator 保存并检查预制体外观；浏览器完整启动至首页，无捕获到的 warning/error。项目业务 TypeScript 无诊断，整体引擎声明仍有既有诊断。TikTok 构建及真机验证由用户完成。
