# 原版关卡与整体补位阶段

## 本阶段交付

- 原始关卡配置进入独立 JSON；严格开放前四关，保留其坐标和排列顺序。
- 25 种水果拥有独立预制体，图片、设计尺寸和多边形顶点来自原 Ball 预制体；共享 FruitItem/FruitVisual 行为脚本。
- 棋盘地形多边形、普通槽锁墙和左右边界取自 watermelonGame.fire。布局使用该场景的 750×1334 设计坐标；没有照搬旧版脚本和 meta。
- 全关一次性生成；点击后仅对未释放水果计算纵向补位，采用原版阈值和正弦缓出时长，动画期间禁止点击。
- GameController 管理通关进度；LevelProgress 独立负责版本化本地存档，读取损坏或无法写入时保留可读提示。
- 结算预制体提供下一关、重开当前关和首页。未知/未开放关卡在 HUD 显示原因，可回首页或主动重玩第一关，不偷偷跳关。
- 现有业务字段、方法参数和关键数值已补中文注释，查值请读 parameter-guide.md。
