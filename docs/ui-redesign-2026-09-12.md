# Tumble Match 界面重制（2026-09-12）

## 已完成界面

- 首页：天空草地背景、动态 Logo、试玩水果、主按钮和四个底部入口。
- 首页设置：音乐、音效、振动、语言、隐私政策和使用条款；不显示“继续游戏”。
- 语言列表：跟随系统、英语、日语、印尼语、泰语、越南语、马来语、菲律宾语和简体中文，当前语言使用绿色高亮与对勾。
- 游戏暂停设置：音乐、音效、振动、继续、重试和返回首页。
- 成功结算：固定英文图片标题 `LEVEL COMPLETE`、通关插画、下一关和首页入口。
- 失败复活：固定英文图片标题 `ONE MORE CHANCE`、激励广告复活和放弃入口。
- 最终失败：固定英文图片标题 `LEVEL FAILED`、重试和首页入口。

## 功能连接

- 首页 Play 进入当前关卡，Themes 打开主题面板。
- Collection 暂时复用主题收藏入口；Daily Gift 和 Rank 在业务页落地前显示“即将开放”。
- 首页设置与游戏暂停设置使用不同的节点结构和按钮集合。
- 语言选择保存到本地，默认跟随系统，切换后立即刷新可见文本。
- 失败时先显示激励广告复活页；关闭后显示最终失败页。
- 结算静态插画不依赖旧 Spine 节点，旧动画节点缺失时不会再产生空引用。

## 适配说明

- 页面继续使用项目的 750×1334 设计坐标与 Cocos Canvas 缩放。
- 首页设置按钮放在设计安全区内，iPhone 14 Pro 与 iPad 10.2 预览均完整可见。
- 所有文字使用 `SHRINK`，为长语言名称和翻译保留宽度。
- 语言列表使用 `ScrollView + Mask + Layout`，九个语言选项可滚动。

- `tools/validate-prefabs.cjs`：全部预制体引用有效。
- Cocos MCP：`PageHome.prefab`、`SettingsPanel.prefab`、`PageGame.prefab` 格式有效。
- 语言、设置生命周期、设置音频、首页预加载、结算、复活与棋盘复活测试通过。
- 浏览器预览：首页、首页设置、语言切换、游戏暂停设置及 iPad 10.2 布局已人工检查。
