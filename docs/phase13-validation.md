# 原版触底危险闪烁

对照 GameSc.tickFloorWarn、flashWarnBalls、restoreFloorWarnColors：普通槽达到3个、扩槽达到4个曾触地形且非消除状态的水果后进入提醒。首帧建立1秒等待，之后每4秒闪一次；有底部相邻同类可消除组合时清除提醒。计数不是“所有已下落水果”或“槽内水果数量”。

FloorWarningRules 独立于失败计时。FruitVisual 使用预制体中已有 Sprite，0.5秒 sineOut 变为(255,128,128,255)，再0.5秒 sineIn恢复原色；不改变刚体、位置或缩放。颜色补间与消除缩放分离；恢复安全、结算、消除、重开和销毁均清理颜色状态。未新增运行时UI节点，也未添加源码没有的警报音。

实测第2关：点击底部红色浆果、绿色水果和右侧黄色水果，捕获触底水果变为红色调及之后恢复原色的两个画面，未触底水果保持原色。通过开发广告扩槽后，三颗水果恢复安全状态并继续向下落。继续落下紫色与左侧不同水果后出现失败结算，结算时可见槽底水果为正常颜色。全程没有预览警告或错误。

测试 test-floor-warning 覆盖3/4阈值、首次等待、重复间隔、可消除抑制、消除排除与重置；test-warning-visual 验证恢复真实原色、防止重复补间、与消除缩放分离、销毁清理。开局顺序及水果生命周期测试通过，业务代码无TypeScript诊断。

边界：扩槽4颗提醒的数值规则已测试，但本次截图未明确捕获其闪烁帧，不冒充视觉验收；可消除后立即取消、冰层/黑洞混合及不同主题仍需实玩回归。复活流程尚未接入，整项目仍未完成。
