# 原版机制提示迁移

对照源 GameSc.js 的 getHintSpriteNameByLevelCfg 和开局提示逻辑，接入每关机制提示。优先级为黑洞、冰层、隐藏、横向、纵向；试玩使用试玩关卡数据。五张主图与隐藏水果文字来自源 assets/resources/sprite/Hint，没有复制旧 meta。

LevelHintView 为 Creator MCP 制作的独立预制体，原尺寸 492×223，位置 (0,200)；隐藏文字尺寸 347×45，位置 (0,-45.175)。弹出 0.25 秒 backOut，停留 1.5 秒，收起 0.25 秒 sineIn。时长沿用原版，修改将改变开局等待长度。

提示期间禁止点击下落、入场推进和初始补位；提示完成后先入场再执行一次纵向补位。即使草稿无需入场位移，也遵守提示顺序。返回时取消提示补间。棋盘序列化绑定提示节点，运行时读取组件；修正了最初直接绑定跨预制体组件为空的错误。

验证：45 个原配置提示选择及混合机制优先级通过；真实 GameBoard 调度测试覆盖提示锁、入场、只执行一次初始补位与零位移边界；入场测试通过；41 个预制体引用有效。assets 业务代码没有 TypeScript 诊断，完整工程仍有既有框架扩展诊断。

浏览器第2关开局后显示40水果和正确进度，重复进入及返回正常；最终新预览页无警告或错误。自动截图未捕获修复后两秒提示的完整中间帧，不能据此宣称五种提示动画逐帧视觉验收完成。隐藏文字、冰层/黑洞/横向提示实际画面及引导期间退出仍需补充回归。
